# Security Policy

## Supported versions

Security fixes are applied to the latest tagged release and the `main` branch.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Report it privately to `austinbrown101@msn.com` with a description, affected version or commit, reproduction steps, and potential impact. You should receive an acknowledgement within seven days.

This research software is provided under the terms of the MIT License and is not intended for safety-critical control without independent validation.
